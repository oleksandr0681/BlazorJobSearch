# JobSearch

Сервіс для пошуку роботи. 

Створено за допомогою **Blazor**, **T-SQL**, **Entity Framework Core**, і **ASP.NET Core Identity** для автентифікації.

---

## Попередні вимоги

- .NET 8.0

## Початок роботи

### 1. Створити копію репозиторію

git clone < repository-url >

### 2. Відкрити проект у Microsoft Visual Studio

### 3. Запустити проект

Debug - Start Debugging

При запуску web-застосунку створюється база даних. У базі даних створюються ролі Employer і JobCandidate.

## Можливості

Кандидати на роботу можуть додавати особисту інформацію, досвід роботи, навички, завантажити резюме та портфоліо.

Роботодавці можуть створювати сторінку компанії з описом, історією, вакансіями та контактами.

Система пошуку вакансій за ключовими словами, місцезнаходженням, типом зайнятості (повна, часткова, стажування).

Кандидати можуть подавати заявки на вакансії. 

Роботодавці отримують сповіщення про нові заявки. 

Є система приватних повідомлень між кандидатами і роботодавцями.
